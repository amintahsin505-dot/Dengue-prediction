Dengue Watch BD - Python 3.14 setup (Windows PowerShell)

1. Open PowerShell in this project folder.
2. Run:
   python -m pip install --upgrade pip
   python -m pip install --only-binary=:all: -r requirements.txt
3. Start the website:
   python app.py
4. Open http://127.0.0.1:5000 in Chrome.

If you previously installed some packages, pip will check and update them to
versions compatible with Python 3.14 based on requirements.txt.
